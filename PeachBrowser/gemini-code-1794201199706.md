# Peach Browser (KMP) — Complete Architectural Audit, Bug Remediation & Feature Upgrade Plan (November 2026)

## 1. Root-Cause Audit Across All Reported Issues

### Issue 1: Login / Sign-up / Sign-in Fails Even With Shield Off
* **Cross-Origin Auth Iframes Ignore Top-Level Shield State**: In `PeachWebView.android.kt` (`isShieldActiveForHost` and `isFarblingActiveForHost`), the bridge evaluates the calling frame's hostname[cite: 1]. Turning Shields off on a website records only the main frame's domain in `siteShieldOverrides`[cite: 1]. Embedded OAuth/SSO iframes (`accounts.google.com`, `appleid.apple.com`, `auth0.com`, `clerk.com`, `challenges.cloudflare.com`) pass their own hostname to `PeachNativeBridge.isShieldActive(currentHost)`, keeping shields and farbling active inside the authentication frame[cite: 1].
* **Destructive `onCreateWindow` & `setSupportMultipleWindows(false)`**: `PeachWebView.android.kt` sets `setSupportMultipleWindows(false)` and defines an `onCreateWindow` callback that forces the popup URL into the main `WebView` (`view.loadUrl(targetUrl)`) and immediately calls `v?.destroy()`[cite: 1]. OAuth 2.0 / OIDC popups (`window.open()`) rely on `window.opener.postMessage()` and check `popup.closed`; destroying the child `WebView` breaks Google, Apple, Microsoft, and GitHub sign-in flows[cite: 1].
* **Navigation Interception in `shouldOverrideUrlLoading`**: `handleUrlLoading` only checks `isSiteException(host)` (ignoring `isShieldActiveForHost(host)`) and runs `UrlSanitizer.stripTrackingParams` and `UrlSanitizer.deAmp` on every URL[cite: 1]. Calling `view.loadUrl(targetUrl)` inside `shouldOverrideUrlLoading` drops HTTP `Referer` headers and `POST` bodies during SSO callback redirects[cite: 1].
 

### Issue 2: Distorted Webpage Window & Broken Website Layouts
* **Mismatched Viewport Settings (`useWideViewPort = true` + `loadWithOverviewMode = false`)**: In `PeachWebView.android.kt`, `useWideViewPort = true` is paired with `loadWithOverviewMode = false` and lacks zoom/layout algorithm settings[cite: 1]. Pages using desktop or hybrid viewports render inside an unscaled 980px virtual width without fitting the device screen[cite: 1].
* **Rigid `MeasureSpec.EXACTLY` Override in `PeachNativeWebView.onMeasure`**: Forcing `MeasureSpec.EXACTLY` on every layout pass breaks dynamic viewport resizing when the soft keyboard (IME) or edge-to-edge system bars animate[cite: 1].
* **Missing `android:windowSoftInputMode="adjustResize"`**: `MainActivity` calls `enableEdgeToEdge()` in `MainActivity.kt` without `adjustResize` in `AndroidManifest.xml`, distorting fixed bottom bars and input fields when the keyboard opens[cite: 1].
* **Broad Cosmetic CSS Selectors on `document.documentElement`**: `privacy_shield.bundle.js` injects `<style>` onto `document.documentElement` before `<head>` exists and applies `height: 0 !important; max-height: 0 !important` to broad selectors (`.ad-container`, `.ad-wrapper`, `[id^="div-gpt-ad"]`), collapsing legitimate flex/grid layouts[cite: 1].

### Issue 3: `chatgpt.com` & Streaming SPAs Hang Mid-Conversation
* **Compose `AndroidView(update = ...)` Recomposition Storm**: Every progress tick, title update, or 1-second download sync triggers the `update` lambda in `PeachWebView.android.kt`[cite: 1]. That block repeatedly sets `webView.settings.javaScriptEnabled = !shouldBlockScripts` (triggering a synchronous Chromium Blink preferences recalculation over JNI) and calls `webView.canGoBackSmartly()` -> `copyBackForwardList()` (a synchronous IPC call copying navigation history on the UI thread)[cite: 1].
* **Forced Synchronous Reflow in `onPageFinished`**: Running `document.body.innerText.substring(0, 3000)` forces Chromium to halt JS execution and compute layout for the entire DOM tree during streaming updates[cite: 1].
* **Cloudflare Turnstile & OpenAI Sentinel PoW Failure**: `farbling.bundle.js` spoofs `WebGLRenderingContext.prototype.getParameter` with hardcoded `'Qualcomm'` / `'Adreno (TM) 740'` and attaches an own `toString` property to patched functions[cite: 1]. Anti-bot proof-of-work scripts running in subframes detect the `Function.prototype.toString` anomaly and GPU mismatch, silently dropping Server-Sent Events (SSE) streams[cite: 1].
* **ServiceWorker Interception Stall**: Hooking `ServiceWorkerControllerCompat` in `AdBlocker.ensureServiceWorkerHooked()` stalls streaming `ReadableStream` / `fetch` responses in modern SPAs[cite: 1].

### Issue 4: Security Flaws, Memory Leaks & Redundant Code
* **Duplicate `setDownloadListener`**: Defined twice in `PeachWebView.android.kt`; the second registration overwrites `enqueuePeachDownload` with an incomplete listener that crashes on `data:` and `blob:` URLs[cite: 1].
* **Activity Context Leak in `AndroidTabWebViewPool`**: `PeachNativeWebView` instances are created with an `Activity` context and stored in a static `ConcurrentHashMap`, leaking `MainActivity` across configuration changes[cite: 1].
* **Cross-Origin Information Leak via `@JavascriptInterface`**: `PeachNativeBridge` exposes `isSiteException(host)` to every frame in the WebView, allowing untrusted third-party scripts to enumerate the user's whitelisted domains[cite: 1].
* **Unconditional 1-Second Polling Loops**: Both `BrowserViewModel.startRealTimeDownloadsSync()` and `DownloadsScreen.kt` run `while (true) { delay(1000L) }` polling `DownloadManager` and disk I/O indefinitely even when zero downloads are active[cite: 1].
* **Escaped String Interpolation Bug in `LlmApiService.kt`**: `header("Authorization", "Bearer \$apiKey")` sends the literal string `"Bearer $apiKey"` instead of interpolating the variable[cite: 1].
* **Broken Cookie Shredding in `PlatformSession.android.kt`**: `shredSiteData(host)` passes a bare hostname without a scheme (`https://`) to `CookieManager.getCookie(cleanHost)`, which returns `null` in Android WebView and leaves cookies intact[cite: 1].

### Issue 5: Missing Persistent Media Notification Bar With Playback Controls
* `PeachMediaService.kt` builds a basic static text notification with no `MediaSession`, no track/artist metadata, and no `Previous`, `Play/Pause`, `Next`, or `Stop` action buttons[cite: 1]. Furthermore, `MainActivity.onResume()` immediately stops `PeachMediaService`, removing the notification bar whenever the user switches back to the browser[cite: 1].

~~~kotlin
package com.example.peachbrowser.util

object UrlSanitizer {

    private val TRACKING_PARAMS = setOf(
        "utm_source", "utm_medium", "utm_campaign", "utm_term", "utm_content",
        "utm_id", "utm_cid", "utm_reader", "utm_viz_id", "utm_pubreferrer",
        "utm_swu", "gclid", "gclsrc", "dclid", "fbclid", "msclkid", "twclid",
        "ttclid", "igshid", "igsh", "mc_cid", "mc_eid", "yclid", "_hsenc",
        "_hsmi", "hsCtaTracking", "mkt_tok", "vero_id", "oly_enc_id",
        "oly_anon_id", "rb_clickid", "s_kwcid", "wickedid", "soc_src", "soc_trk"
    )

    private val AUTH_AND_SSO_HOSTS = setOf(
        "accounts.google.com",
        "appleid.apple.com",
        "login.microsoftonline.com",
        "login.live.com",
        "github.com",
        "auth0.com",
        "clerk.com",
        "okta.com",
        "duosecurity.com",
        "auth.openai.com",
        "chatgpt.com",
        "claude.ai"
    )

    private val AUTH_PATH_KEYWORDS = listOf(
        "/oauth", "/authorize", "/login", "/signin", "/sign-in",
        "/signup", "/sign-up", "/callback", "/auth", "/sso", "/saml", "/token"
    )

    fun isAuthOrOAuthUrl(url: String): Boolean {
        val lower = url.lowercase()
        val host = extractHost(lower)
        if (AUTH_AND_SSO_HOSTS.any { host == it || host.endsWith(".$it") }) {
            return true
        }
        if (AUTH_PATH_KEYWORDS.any { lower.contains(it) }) {
            return true
        }
        if (lower.contains("client_id=") ||
            lower.contains("redirect_uri=") ||
            lower.contains("response_type=") ||
            lower.contains("code_challenge=") ||
            lower.contains("id_token=") ||
            lower.contains("access_token=")
        ) {
            return true
        }
        return false
    }

    fun stripTrackingParams(url: String): String {
        if (url.isBlank() || (!url.startsWith("http://") && !url.startsWith("https://"))) {
            return url
        }
        if (isAuthOrOAuthUrl(url)) {
            return url
        }

        val hashIndex = url.indexOf('#')
        val fragment = if (hashIndex != -1) url.substring(hashIndex) else ""
        val urlWithoutFragment = if (hashIndex != -1) url.substring(0, hashIndex) else url

        val queryIndex = urlWithoutFragment.indexOf('?')
        if (queryIndex == -1) return url

        val basePath = urlWithoutFragment.substring(0, queryIndex)
        val rawQuery = urlWithoutFragment.substring(queryIndex + 1)
        if (rawQuery.isBlank()) return url

        val allPairs = rawQuery.split('&')
        val keptParams = allPairs.filter { pair ->
            val key = pair.substringBefore('=').lowercase()
            key.isNotBlank() && !TRACKING_PARAMS.contains(key)
        }

        return when {
            keptParams.size == allPairs.size -> url
            keptParams.isEmpty() -> "$basePath$fragment"
            else -> "$basePath?${keptParams.joinToString("&")}$fragment"
        }
    }

    fun deAmp(url: String): String {
        if (url.isBlank() || isAuthOrOAuthUrl(url)) return url
        val lower = url.lowercase()
        val googleAmpIdx = lower.indexOf("/amp/s/")
        if (googleAmpIdx != -1 && (lower.contains("google.") || lower.contains("ampproject.org"))) {
            val remainder = url.substring(googleAmpIdx + "/amp/s/".length)
            return if (remainder.startsWith("http://") || remainder.startsWith("https://")) {
                remainder
            } else {
                "https://$remainder"
            }
        }
        return url
    }

    private fun extractHost(url: String): String {
        return url.removePrefix("https://")
            .removePrefix("http://")
            .substringBefore("/")
            .substringBefore("?")
            .substringBefore(":")
    }
}
~~~

~~~kotlin
package com.example.peachbrowser.webview

import android.content.Context
import android.content.MutableContextWrapper
import android.view.ViewGroup
import java.util.concurrent.ConcurrentHashMap

object AppBackgroundTracker {
    @Volatile
    var isBackgrounded: Boolean = false
        private set

    fun updateBackgroundState(flag: Boolean) {
        isBackgrounded = flag
        AndroidTabWebViewPool.setAppBackgrounded(flag)
    }
}

object AndroidTabWebViewPool {
    private val pool = ConcurrentHashMap<String, PeachNativeWebView>()

    fun getOrCreate(
        tabId: String,
        context: Context,
        factory: (Context) -> PeachNativeWebView
    ): PeachNativeWebView {
        val existing = pool[tabId]
        if (existing != null) {
            (existing.context as? MutableContextWrapper)?.baseContext = context
            (existing.parent as? ViewGroup)?.removeView(existing)
            existing.layoutParams = ViewGroup.LayoutParams(
                ViewGroup.LayoutParams.MATCH_PARENT,
                ViewGroup.LayoutParams.MATCH_PARENT
            )
            return existing
        }
        val wrapper = MutableContextWrapper(context)
        val created = factory(wrapper).apply {
            layoutParams = ViewGroup.LayoutParams(
                ViewGroup.LayoutParams.MATCH_PARENT,
                ViewGroup.LayoutParams.MATCH_PARENT
            )
        }
        pool[tabId] = created
        return created
    }

    fun get(tabId: String): PeachNativeWebView? = pool[tabId]

    fun remove(tabId: String) {
        val webView = pool.remove(tabId) ?: return
        try {
            webView.hideCustomViewIfShowing()
            webView.dismissOAuthPopupIfShowing()
            (webView.context as? MutableContextWrapper)?.baseContext = webView.context.applicationContext
            (webView.parent as? ViewGroup)?.removeView(webView)
            webView.stopLoading()
            webView.clearHistory()
            webView.removeAllViews()
            webView.destroy()
        } catch (e: Exception) {
            e.printStackTrace()
        }
    }

    fun clearAll() {
        val keys = pool.keys().toList()
        for (key in keys) {
            remove(key)
        }
    }

    fun setAppBackgrounded(flag: Boolean) {
        pool.values.forEach { webView ->
            try {
                webView.post {
                    webView.evaluateJavascript(
                        "window.__PEACH_APP_BACKGROUNDED__ = $flag;",
                        null
                    )
                }
            } catch (e: Exception) {
                e.printStackTrace()
            }
        }
    }

    fun dispatchMediaControl(action: String) {
        pool.values.forEach { webView ->
            try {
                webView.post {
                    webView.evaluateJavascript(
                        """
                        (function() {
                            if (typeof window.__PEACH_MEDIA_CONTROL__ === 'function') {
                                window.__PEACH_MEDIA_CONTROL__('$action');
                            }
                        })();
                        """.trimIndent(),
                        null
                    )
                }
            } catch (e: Exception) {
                e.printStackTrace()
            }
        }
    }

    fun pauseAllMedia() {
        dispatchMediaControl("pause")
    }

    fun resumeActiveMedia() {
        dispatchMediaControl("play")
    }

    fun skipToNextMedia() {
        dispatchMediaControl("next")
    }

    fun skipToPreviousMedia() {
        dispatchMediaControl("previous")
    }

    fun duckAllMedia() {
        pool.values.forEach { webView ->
            try {
                webView.post {
                    webView.evaluateJavascript(
                        "if (typeof window.__PEACH_DUCK_MEDIA__ === 'function') window.__PEACH_DUCK_MEDIA__(true);",
                        null
                    )
                }
            } catch (e: Exception) {
                e.printStackTrace()
            }
        }
    }

    fun unduckAllMedia() {
        pool.values.forEach { webView ->
            try {
                webView.post {
                    webView.evaluateJavascript(
                        "if (typeof window.__PEACH_DUCK_MEDIA__ === 'function') window.__PEACH_DUCK_MEDIA__(false);",
                        null
                    )
                }
            } catch (e: Exception) {
                e.printStackTrace()
            }
        }
    }
}
~~~

~~~kotlin
    fun isDomainMatching(host: String, domainSet: Set<String>): Boolean {
        if (host.isBlank()) return false
        val clean = host.trim().lowercase()
        return domainSet.any { clean == it || clean.endsWith(".$it") }
    }

    fun isAdRequest(url: Uri): Boolean {
        val host = (url.host ?: "").lowercase()
        if (host.isBlank()) return false
        if (isDomainMatching(host, ESSENTIAL_STATIC_AND_SPA_DOMAINS)) {
            val path = url.path ?: ""
            if ((host.endsWith("youtube.com") || host == "youtube.com") &&
                (path.startsWith("/api/stats/ads") || path.startsWith("/pagead/") || path.startsWith("/ptracking"))
            ) {
                return true
            }
            return false
        }
        return isDomainMatching(host, AD_HOSTS)
    }

            "text/plain",
            "UTF-8",
            204,
            "No Content",
            headers,

        )
    }

private fun loadAssetScript(context: Context, fileName: String): String {
    return try {
        context.assets.open(fileName).bufferedReader().use { it.readText() }
    } catch (e: Exception) {
        ""
    }
}

private fun sanitizeUserAgentForOAuth(defaultUa: String): String {
    return defaultUa
        .replace("; wv)", ")")
        .replace("; wv;", ";")
        .replace("; wv", "")
        .replace(Regex("Version/\\d+\\.\\d+\\s?"), "")
        .trim()
}

private fun enqueuePeachDownload(
    ctx: Context,
    downloadUrl: String,
    userAgent: String?,
    contentDisposition: String?,
    mimetype: String?,
    browserViewModel: BrowserViewModel
) {
    try {
        val now = com.example.peachbrowser.currentTimeMillis()
        if (downloadUrl.startsWith("blob:")) {
            Toast.makeText(ctx, "Blob stream download handled by page", Toast.LENGTH_SHORT).show()
            return
        }
        if (downloadUrl.startsWith("data:")) {
            val commaIndex = downloadUrl.indexOf(',')
            if (commaIndex != -1) {
                val meta = downloadUrl.substring(5, commaIndex)
                val dataPart = downloadUrl.substring(commaIndex + 1)
                val mime = meta.substringBefore(';').ifBlank { "image/png" }
                val ext = MimeTypeMap.getSingleton().getExtensionFromMimeType(mime) ?: "png"
                val fileName = "peach_file_$now.$ext"
                val downloadsDir = Environment.getExternalStoragePublicDirectory(Environment.DIRECTORY_DOWNLOADS)
                downloadsDir.mkdirs()
                val destFile = File(downloadsDir, fileName)
                val bytes = if (meta.contains("base64", ignoreCase = true)) {
                    Base64.decode(dataPart, Base64.DEFAULT)
                } else {
                    Uri.decode(dataPart).toByteArray()
                }
                FileOutputStream(destFile).use { it.write(bytes) }
                MediaScannerConnection.scanFile(ctx, arrayOf(destFile.absolutePath), arrayOf(mime), null)
                browserViewModel.processIntent(
                    BrowserIntent.AddDownload(
                        DownloadItem(
                            id = -now,
                            fileName = fileName,
                            url = "data:$mime",
                            mimeType = mime,
                            progress = 100,
                            isCompleted = true,
                            localUri = Uri.fromFile(destFile).toString(),
                            filePath = destFile.absolutePath,
                            bytesDownloaded = bytes.size.toLong(),
                            totalBytes = bytes.size.toLong(),
                            timestamp = now
                        )
                    )
                )
                Toast.makeText(ctx, "Saved $fileName to Downloads", Toast.LENGTH_SHORT).show()
            }
            return
        }

        val resolvedMime = if (!mimetype.isNullOrBlank() && mimetype != "application/octet-stream") {
            mimetype
        } else {
            val ext = MimeTypeMap.getFileExtensionFromUrl(downloadUrl)
            MimeTypeMap.getSingleton().getMimeTypeFromExtension(ext.lowercase()) ?: (mimetype ?: "*/*")
        }
        val guessedFileName = URLUtil.guessFileName(downloadUrl, contentDisposition, resolvedMime)
        val destFile = File(
            Environment.getExternalStoragePublicDirectory(Environment.DIRECTORY_DOWNLOADS),
            guessedFileName
        )

        val dm = ctx.getSystemService(Context.DOWNLOAD_SERVICE) as DownloadManager
        val request = DownloadManager.Request(Uri.parse(downloadUrl)).apply {
            if (!resolvedMime.isNullOrBlank()) {
                setMimeType(resolvedMime)
            }
            val cookies = CookieManager.getInstance().getCookie(downloadUrl)
            if (!cookies.isNullOrBlank()) {
                addRequestHeader("cookie", cookies)
            }
            if (!userAgent.isNullOrBlank()) {
                addRequestHeader("User-Agent", userAgent)
            }
            setDescription("Downloading with Peach Browser...")
            setTitle(guessedFileName)
            setNotificationVisibility(DownloadManager.Request.VISIBILITY_VISIBLE_NOTIFY_COMPLETED)
            setDestinationInExternalPublicDir(Environment.DIRECTORY_DOWNLOADS, guessedFileName)
        }
        val downloadId = dm.enqueue(request)
        browserViewModel.processIntent(
            BrowserIntent.AddDownload(
                DownloadItem(
                    id = downloadId,
                    fileName = guessedFileName,
                    url = downloadUrl,
                    mimeType = resolvedMime ?: "",
                    progress = 5,
                    isCompleted = false,
                    localUri = null,
                    filePath = destFile.absolutePath,
                    timestamp = now
                )
            )
        )
        Toast.makeText(ctx, "Downloading $guessedFileName...", Toast.LENGTH_SHORT).show()
    } catch (e: Exception) {
        e.printStackTrace()
        Toast.makeText(ctx, "Download failed: ${e.message}", Toast.LENGTH_SHORT).show()
    }
}

class PeachNativeWebView(context: Context) : WebView(context) {
    @Volatile var isBackgroundPlayActive: Boolean = true
    @Volatile var isShieldEnabled: Boolean = true
    @Volatile var isFarblingEnabled: Boolean = true
    @Volatile var isTrackingProtectionEnabled: Boolean = true
    @Volatile var isDeAmpEnabled: Boolean = true
    @Volatile var siteShieldOverrides: Map<String, SiteShieldConfig> = emptyMap()
    @Volatile var siteExceptions: Set<String> = emptySet()
    @Volatile var currentMainFrameHost: String = ""
    @Volatile var appliedReloadTrigger: Int = 0
    @Volatile var cachedCanGoBackSmartly: Boolean = false

    var customView: View? = null
    var customViewCallback: WebChromeClient.CustomViewCallback? = null
    var customViewContainer: FrameLayout? = null
    var oauthPopupDialog: Dialog? = null
    var oauthPopupWebView: WebView? = null
    var originalOrientation: Int = ActivityInfo.SCREEN_ORIENTATION_UNSPECIFIED
    var onFullscreenChanged: ((Boolean) -> Unit)? = null
    var onPermissionRequestHandler: ((PermissionRequest) -> Unit)? = null
    var onPermissionRequestCanceledHandler: ((PermissionRequest) -> Unit)? = null
    var onImageLongPressHandler: ((String) -> Unit)? = null

    init {
        layoutParams = ViewGroup.LayoutParams(
            ViewGroup.LayoutParams.MATCH_PARENT,
            ViewGroup.LayoutParams.MATCH_PARENT
        )
        isFocusable = true
        isFocusableInTouchMode = true
    }

    private fun normalizeHost(raw: String): String {
        return raw.trim()
            .lowercase()
            .removePrefix("https://")
            .removePrefix("http://")
            .substringBefore("/")
            .substringBefore("?")
            .substringBefore(":")
            .removePrefix("www.")
    }

    fun isSiteException(host: String): Boolean {
        val cleanHost = normalizeHost(host)
        val mainHost = normalizeHost(currentMainFrameHost)
        if (mainHost.isNotBlank() && siteExceptions.any { mainHost == it || mainHost.endsWith(".$it") }) {
            return true
        }
        if (cleanHost.isBlank()) return false
        return siteExceptions.any { cleanHost == it || cleanHost.endsWith(".$it") }
    }

    fun isShieldActiveForHost(host: String): Boolean {
        if (isSiteException(host)) return false
        val mainHost = normalizeHost(currentMainFrameHost)
        val mainOverride = if (mainHost.isNotBlank()) {
            siteShieldOverrides.entries.find { mainHost == it.key || mainHost.endsWith(".${it.key}") }?.value
        } else null
        if (mainOverride != null) {
            return mainOverride.shieldsUp && mainOverride.blockTrackersAndAds
        }
        val cleanHost = normalizeHost(host)
        val hostOverride = if (cleanHost.isNotBlank()) {
            siteShieldOverrides.entries.find { cleanHost == it.key || cleanHost.endsWith(".${it.key}") }?.value
        } else null
        return if (hostOverride != null) {
            hostOverride.shieldsUp && hostOverride.blockTrackersAndAds
        } else {
            isShieldEnabled
        }
    }

    fun isFarblingActiveForHost(host: String): Boolean {
        if (isSiteException(host)) return false
        val mainHost = normalizeHost(currentMainFrameHost)
        val mainOverride = if (mainHost.isNotBlank()) {
            siteShieldOverrides.entries.find { mainHost == it.key || mainHost.endsWith(".${it.key}") }?.value
        } else null
        if (mainOverride != null) {
            return mainOverride.shieldsUp && mainOverride.blockFingerprinting
        }
        val cleanHost = normalizeHost(host)
        val hostOverride = if (cleanHost.isNotBlank()) {
            siteShieldOverrides.entries.find { cleanHost == it.key || cleanHost.endsWith(".${it.key}") }?.value
        } else null
        return if (hostOverride != null) {
            hostOverride.shieldsUp && hostOverride.blockFingerprinting
        } else {
            isFarblingEnabled
        }
    }

        try {

            oauthPopupWebView?.destroy()

    fun hideCustomViewIfShowing() {
        val cv = customView ?: return

        val decorView = act?.window?.decorView as? ViewGroup

        customViewContainer?.let { container ->
            container.removeView(cv)
            decorView?.removeView(container)
        }

        customViewCallback?.onCustomViewHidden()
        customView = null

        act?.let { a ->
            a.requestedOrientation = originalOrientation
            val insetsController = WindowCompat.getInsetsController(a.window, a.window.decorView)
            insetsController.show(WindowInsetsCompat.Type.systemBars())
        }

        onFullscreenChanged?.invoke(false)
    }

    private fun isSamePageOrRedirect(url1: String, url2: String): Boolean {
        if (url1.isBlank() || url2.isBlank()) return false
        if (url1 == url2) return true
        val clean1 = url1.removeSuffix("/").removePrefix("https://").removePrefix("http://")
        val clean2 = url2.removeSuffix("/").removePrefix("https://").removePrefix("http://")
        if (clean1 == clean2) return true

        val noHash1 = clean1.substringBefore("#")
        val noHash2 = clean2.substringBefore("#")
        val query1 = noHash1.substringAfter("?", "")
        val query2 = noHash2.substringAfter("?", "")
        if (query1 != query2) return false

        val base1 = noHash1.substringBefore("?")
        val base2 = noHash2.substringBefore("?")
        return base1.removePrefix("m.").removePrefix("www.") == base2.removePrefix("m.").removePrefix("www.")
    }

    fun refreshSmartBackCache(): Boolean {
        if (!canGoBack()) {
            cachedCanGoBackSmartly = false
            return false
        }
        val list = copyBackForwardList()
        val currIndex = list.currentIndex
        if (currIndex <= 0) {
            cachedCanGoBackSmartly = false
            return false
        }
        val currUrl = list.getItemAtIndex(currIndex)?.url ?: ""
        var targetIndex = currIndex - 1
        while (targetIndex >= 0) {
            val targetUrl = list.getItemAtIndex(targetIndex)?.url ?: ""
            if (!isSamePageOrRedirect(currUrl, targetUrl)) {
                cachedCanGoBackSmartly = true
                return true
            }
            targetIndex--
        }
        cachedCanGoBackSmartly = false
        return false
    }

    fun goBackSmartly(): Boolean {
        if (!canGoBack()) return false
        val list = copyBackForwardList()
        val currIndex = list.currentIndex
        if (currIndex <= 0) return false

        val currUrl = list.getItemAtIndex(currIndex)?.url ?: ""
        var targetIndex = currIndex - 1
        while (targetIndex >= 0) {
            val targetUrl = list.getItemAtIndex(targetIndex)?.url ?: ""
            if (!isSamePageOrRedirect(currUrl, targetUrl)) {
                break
            }
            targetIndex--
        }

        if (targetIndex >= 0) {
            val steps = targetIndex - currIndex
            goBackOrForward(steps)
            return true
        }
        return false
    }

    override fun onWindowVisibilityChanged(visibility: Int) {
        if (isBackgroundPlayActive && (visibility == View.GONE || visibility == View.INVISIBLE)) {
            super.onWindowVisibilityChanged(View.VISIBLE)
            return
        }
        super.onWindowVisibilityChanged(visibility)
    }

    override fun dispatchWindowVisibilityChanged(visibility: Int) {
        if (isBackgroundPlayActive && (visibility == View.GONE || visibility == View.INVISIBLE)) {
            super.dispatchWindowVisibilityChanged(View.VISIBLE)
            return
        }
        super.dispatchWindowVisibilityChanged(visibility)
    }

    override fun onVisibilityChanged(changedView: View, visibility: Int) {
        if (isBackgroundPlayActive && (visibility == View.GONE || visibility == View.INVISIBLE)) {
            super.onVisibilityChanged(changedView, View.VISIBLE)
            return
        }
        super.onVisibilityChanged(changedView, visibility)
    }

    override fun onPause() {
        if (isBackgroundPlayActive) return
        super.onPause()
    }

    override fun pauseTimers() {
        if (isBackgroundPlayActive) return
        super.pauseTimers()
    }
}

@Composable
actual fun PeachWebView(
    tabId: String,
    url: String,
    controller: PeachWebViewController?,
    modifier: Modifier
) {
    val browserViewModel = koinInject<BrowserViewModel>()
    val browserState by browserViewModel.state.collectAsState()
    val lifecycleOwner = LocalLifecycleOwner.current
    val context = LocalContext.current
    val activity = context.findActivity()

    val backgroundScript = remember(context) { loadAssetScript(context, "background_playback.bundle.js") }
    val farblingScript = remember(context) { loadAssetScript(context, "farbling.bundle.js") }
    val mediaDetectorScript = remember(context) { loadAssetScript(context, "media_detector.bundle.js") }
    val shieldScript = remember(context) { loadAssetScript(context, "privacy_shield.bundle.js") }

    var longPressedImageUrl by remember { mutableStateOf<String?>(null) }
    val audioFocusManager = koinInject<com.example.peachbrowser.util.PeachAudioFocusManager>()
    var pendingPermissionRequest by remember { mutableStateOf<PermissionRequest?>(null) }

    val permissionLauncher = rememberLauncherForActivityResult(
        ActivityResultContracts.RequestMultiplePermissions()
    ) { permissions ->
        val pendingReq = pendingPermissionRequest
        if (pendingReq != null) {
            val allGranted = permissions.isNotEmpty() && permissions.entries.all { it.value }
            if (allGranted) {
                val originStr = pendingReq.origin.toString()
                val resources = pendingReq.resources
                SessionPermissionManager.grantResources(tabId, originStr, resources)
                try {
                    pendingReq.grant(resources)
                } catch (e: Exception) {
                    e.printStackTrace()
                }
            } else {
                try {
                    pendingReq.deny()
                } catch (e: Exception) {
                    e.printStackTrace()
                }
            }
            pendingPermissionRequest = null
        }
    }

    val handlePermissionRequest: (PermissionRequest) -> Unit = { request ->
        val originStr = request.origin.toString()
        if (SessionPermissionManager.hasAllResources(tabId, originStr, request.resources)) {
            try {
                request.grant(request.resources)
            } catch (e: Exception) {
                e.printStackTrace()
            }
        } else {
            pendingPermissionRequest = request
            val requiredOsPermissions = mutableListOf<String>()
            for (res in request.resources) {
                if (res == PermissionRequest.RESOURCE_VIDEO_CAPTURE) {
                    requiredOsPermissions.add(Manifest.permission.CAMERA)
                } else if (res == PermissionRequest.RESOURCE_AUDIO_CAPTURE) {
                    requiredOsPermissions.add(Manifest.permission.RECORD_AUDIO)
                }
            }
            if (requiredOsPermissions.isNotEmpty()) {
                permissionLauncher.launch(requiredOsPermissions.toTypedArray())
            } else {
                SessionPermissionManager.grantResources(tabId, originStr, request.resources)
                try {
                    request.grant(request.resources)
                } catch (e: Exception) {
                    e.printStackTrace()
                }
                pendingPermissionRequest = null
            }
        }
    }

    val handlePermissionRequestCanceled: (PermissionRequest) -> Unit = { request ->
        if (pendingPermissionRequest == request) {
            pendingPermissionRequest = null
        }
    }

    AndroidView(
        modifier = modifier.fillMaxSize(),
        factory = { ctx ->
            AdBlocker.globalShieldEnabled = browserState.isAdBlockEnabled
            AdBlocker.globalSiteExceptions = browserState.siteExceptions

            AndroidTabWebViewPool.getOrCreate(tabId, ctx) { c ->
                PeachNativeWebView(c).apply {
                    onPermissionRequestHandler = handlePermissionRequest
                    onPermissionRequestCanceledHandler = handlePermissionRequestCanceled
                    isBackgroundPlayActive = browserState.isBackgroundPlayEnabled
                    isShieldEnabled = browserState.isAdBlockEnabled
                    isFarblingEnabled = browserState.isFarblingEnabled
                    isTrackingProtectionEnabled = browserState.isTrackingProtectionEnabled
                    isDeAmpEnabled = browserState.isDeAmpEnabled
                    siteShieldOverrides = browserState.siteShieldOverrides
                    siteExceptions = browserState.siteExceptions
                    appliedReloadTrigger = browserState.shouldReloadTrigger
                    isNestedScrollingEnabled = true

                    onImageLongPressHandler = { imgUrl -> longPressedImageUrl = imgUrl }
                    setOnLongClickListener { v ->
                        val wv = v as? WebView ?: return@setOnLongClickListener false
                        val hit = wv.hitTestResult
                        if (hit.type == WebView.HitTestResult.IMAGE_TYPE ||
                            hit.type == WebView.HitTestResult.SRC_IMAGE_ANCHOR_TYPE
                        ) {
                            val extraUrl = hit.extra
                            if (!extraUrl.isNullOrBlank()) {
                                onImageLongPressHandler?.invoke(extraUrl)
                                return@setOnLongClickListener true
                            }
                        }
                        false
                    }

                    setDownloadListener { downloadUrl, userAgent, contentDisposition, mimetype, _ ->
                        enqueuePeachDownload(ctx, downloadUrl, userAgent, contentDisposition, mimetype, browserViewModel)
                    }

                    settings.apply {
                        javaScriptEnabled = true
                        domStorageEnabled = true
                        databaseEnabled = true
                        cacheMode = WebSettings.LOAD_DEFAULT
                        mixedContentMode = WebSettings.MIXED_CONTENT_COMPATIBILITY_MODE
                        setSupportMultipleWindows(true)
                        javaScriptCanOpenWindowsAutomatically = true
                        allowFileAccess = false
                        allowContentAccess = true
                        mediaPlaybackRequiresUserGesture = false
                        useWideViewPort = true
                        loadWithOverviewMode = true
                        setSupportZoom(true)
                        builtInZoomControls = true
                        displayZoomControls = false
                        textZoom = 100
                        layoutAlgorithm = WebSettings.LayoutAlgorithm.NORMAL
                        userAgentString = sanitizeUserAgentForOAuth(userAgentString ?: "")
                    }

                    if (WebViewFeature.isFeatureSupported(WebViewFeature.REQUESTED_WITH_HEADER_ALLOW_LIST)) {
                        try {
                            WebSettingsCompat.setRequestedWithHeaderOriginAllowList(settings, emptySet())
                        } catch (e: Exception) {
                            e.printStackTrace()
                        }
                    }

                    try {
                        val cm = CookieManager.getInstance()
                        cm.setAcceptCookie(true)
                        cm.setAcceptThirdPartyCookies(this, true)
                    } catch (e: Exception) {
                        e.printStackTrace()
                    }

                    webViewClient = object : WebViewClient() {
                        override fun shouldInterceptRequest(
                            view: WebView?,
                            request: WebResourceRequest?
                        ): WebResourceResponse? {
                            if (request == null) return null
                            val reqUri = request.url ?: return super.shouldInterceptRequest(view, request)
                            val reqHost = (reqUri.host ?: "").lowercase()
                            val nativeView = view as? PeachNativeWebView

                            if (request.isForMainFrame) {
                                if (reqHost.isNotBlank()) {
                                    nativeView?.currentMainFrameHost = reqHost
                                    AdBlocker.currentMainFrameHost = reqHost
                                }
                                return super.shouldInterceptRequest(view, request)
                            }

                            if (reqHost.isBlank()) return super.shouldInterceptRequest(view, request)

                            val refererHeader = request.requestHeaders?.get("Referer")
                                ?: request.requestHeaders?.get("referer")
                                ?: ""
                            val pageOriginHost = try {
                                Uri.parse(refererHeader).host?.lowercase() ?: ""
                            } catch (e: Exception) {
                                ""
                            }
                            val effectiveOriginHost = pageOriginHost.ifBlank { nativeView?.currentMainFrameHost ?: "" }

                            if (nativeView?.isSiteException(reqHost) == true ||
                                (effectiveOriginHost.isNotBlank() && nativeView?.isSiteException(effectiveOriginHost) == true)
                            ) {
                                return super.shouldInterceptRequest(view, request)
                            }

                            val shieldActive = if (effectiveOriginHost.isNotBlank()) {
~~~

~~~kotlin
                AndroidTabWebViewPool.skipToPreviousMedia()
                updateMediaSessionAndNotification()
                return START_STICKY
            }
            ACTION_START, ACTION_UPDATE -> {
                intent.getStringExtra(EXTRA_TITLE)?.takeIf { it.isNotBlank() }?.let {
                    currentTitle = it
                }
                intent.getStringExtra(EXTRA_ARTIST)?.takeIf { it.isNotBlank() }?.let {
                    currentArtist = it
                }
                if (intent.hasExtra(EXTRA_IS_PLAYING)) {
                    isPlaying = intent.getBooleanExtra(EXTRA_IS_PLAYING, true)
                }
                startForegroundPlayback()
                return START_STICKY
            }
        }

        startForegroundPlayback()
        return START_STICKY
    }

    private fun updateMediaSessionState() {
        val session = mediaSession ?: return
        val stateCode = if (isPlaying) PlaybackState.STATE_PLAYING else PlaybackState.STATE_PAUSED
        val playbackState = PlaybackState.Builder()
            .setActions(
                PlaybackState.ACTION_PLAY or
                        PlaybackState.ACTION_PAUSE or
                        PlaybackState.ACTION_PLAY_PAUSE or
                        PlaybackState.ACTION_SKIP_TO_NEXT or
                        PlaybackState.ACTION_SKIP_TO_PREVIOUS or
                        PlaybackState.ACTION_STOP
            )
            .setState(stateCode, PlaybackState.PLAYBACK_POSITION_UNKNOWN, if (isPlaying) 1.0f else 0f)
            .build()

            .putString(MediaMetadata.METADATA_KEY_ARTIST, currentArtist)
~~~

~~~kotlin
actual fun shredSiteData(host: String) {
    try {
        val cleanHost = host.trim().lowercase()
            .removePrefix("https://")
            .removePrefix("http://")
            .substringBefore("/")
        if (cleanHost.isBlank()) return

        val webStorage = WebStorage.getInstance()
        webStorage.deleteOrigin("https://$cleanHost")
        webStorage.deleteOrigin("http://$cleanHost")

        val cookieManager = CookieManager.getInstance()
        listOf("https://$cleanHost", "http://$cleanHost", "https://www.$cleanHost").forEach { originUrl ->
            val cookies = cookieManager.getCookie(originUrl)
            if (!cookies.isNullOrBlank()) {
                for (part in cookies.split(";")) {
                    val cookieName = part.substringBefore("=").trim()
                    if (cookieName.isNotEmpty()) {
                        cookieManager.setCookie(originUrl, "$cookieName=; Path=/; Max-Age=0")
                        cookieManager.setCookie(originUrl, "$cookieName=; Domain=.$cleanHost; Path=/; Max-Age=0")
                    }
                }
            }
        }
        cookieManager.flush()
    } catch (e: Exception) {
        e.printStackTrace()
    }
}
~~~
